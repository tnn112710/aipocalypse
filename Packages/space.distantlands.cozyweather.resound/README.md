Select one or more audio clips in the Project window and choose **Assets > Create > Distant Lands > Cozy > Resound Tracks From Selected Audio Clips** to create a Resound Track for each clip.

Tracks are saved alongside clips inside the `Assets` folder. Clips stored in packages create tracks in the `Assets` root.

Create a **Distant Lands > Cozy > FX > ReSound FX** profile to temporarily play a specific ReSound track while a COZY FX is active. Configure its priority and choose separate transitions for when the FX starts and ends. **Play After Current Track** waits for the currently playing clip to finish before changing tracks.

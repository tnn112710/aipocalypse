# Official design

Finalized design only: rules the user has confirmed as decided. Everything else in `docs/gdd/` is working draft.

## Rules

- **Only the user promotes.** Content moves here when the user says it is final, never on an agent's judgment.
- **No open items.** No `(???)`, `[TBD]`, proposals or open questions in this folder. If a detail is still open, the decided part comes here and the open part stays in the draft topic file (or `IDEAS.md`), linked from here.
- **One home per rule.** On promotion, move the text here and replace it in the draft file with a link; don't keep two copies.
- **Changing a final rule** is a user decision too: discuss it in the draft file or `IDEAS.md`, then update this folder once agreed.
- Keep files short and precise, one file per topic, with the date each topic was finalized. Start each one from [_TEMPLATE.md](_TEMPLATE.md).

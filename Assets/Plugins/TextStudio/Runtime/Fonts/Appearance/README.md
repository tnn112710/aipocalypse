# Appearance Gallery Fonts

These fonts provide the typography used by both Appearance gallery previews and newly created examples. Each folder contains the original font file, its SIL Open Font License, and a separately generated TextMesh Pro font asset. Applying an Appearance preset to existing text preserves the existing font.

The unmodified font files and licenses were copied from the corresponding licensed Audiowide, Bebas Neue, Bungee, and Cinzel Decorative sources already distributed in the source workspace. These assets have independent Unity identities and do not require Text Studio 3D.

The gallery assets use 90-point sampling, 9-pixel atlas padding, dynamic character population, and additional atlas pages. Their sample characters are populated before distribution. Keep each OFL.txt beside its font when redistributing these assets.

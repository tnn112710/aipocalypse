# Text Studio Visual Design Textures

These seamless 512 by 512 textures are original Text Studio assets licensed with Text Studio. The premium material textures include reviewed runtime derivatives of the user-provided 2026-08-23 styling handoff and the human-approved 2026-09-03 generated brushed gold, weathered steel, and ancient limestone sources. Fine Paper and Holographic Speckle remain deterministic procedural originals. The high-resolution source pixels and checksum provenance live only in the editor-only Text Studio Debug package and are not redistributed in runtime builds.

The shipped imports use sRGB color, no unused alpha channel, repeat wrapping, trilinear filtering, Kaiser-filtered mipmaps, anisotropy 4, high-quality compression, and a 512-pixel maximum size that matches the runtime texture-array resolution. Stable resource IDs in the preset assets provide deterministic texture-array identity. The builder compares encoded bytes before writing, so rebuilding an unchanged collection does not churn the source payload.

`TextStudioPremiumTexturePipeline` owns the approved premium derivatives and validates their source hashes, dimensions, effective alpha, seams, unique payloads, channel meanings, and importer settings. `TextStudioVisualDesignAssetBuilder` preserves reviewed files when rebuilding presets. Missing title textures are reconstructed from their approved sources; the original handoff library retains its explicit missing-file fallback. Rebuilds must preserve seamless periodic sampling, unique payloads, bounded per-file and total package size, and the import contract above. Material recipes use Cover fitting to preserve surface proportions on wide titles, with bounded scale controls for fine weave and mineral fissures.

# Reveal timing recipes

Twelve groups retain all thirty-six shared presets: three timing models, three reveal units, both directions and final reading pause on or off. Each group shows its three units together. Three additional groups demonstrate instant words, reveal speed and native disappearance.

Inspect the native text and shared preset for configuration. Pause, scrub, replay and hide through native authoring preview. The small observer changes only its status label and records actual glyph and completion events; it never replaces text, timing assets or motion policy. Its public timing properties expose the last glyph and completion times for code inspection.

# Placement recipes

Choose a path folder, then a corner-deformation prefab. Each group compares follow-path and outward orientation with short and long source text. All paths, markup and native preview settings are authored on the text hosts. The main scene shows whole-text Custom Curve and one selected phrase that bends along a shallow custom curve. Its em selector is also used by gentle motion and the Appearance fill.

Motion policy, pause and scrubbing remain available through native Text Studio authoring and preview.

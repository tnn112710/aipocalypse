# Caption recipes

Open `../../../02_Effects/Accessible Captions.unity`. Speaker, offscreen and environmental captions remain readable over the authored Relay Ridge environment. Text size and reduced motion are visible controls; additional width, background, instant-text, pause and replacement settings remain on the controller.

`Assets/RelayRidgeSubtitleCues.asset` preserves six English, French and German cue recipes, including timed pauses and inline `<em>` ranges. The focused scene's Relay Dialogue style renders the emphasis and supports localized wrapping. `../Prefabs/SubtitlePanel.prefab` remains a reusable punctuation-paced word-reveal view.

Use the separate Text Studio Unity Localization integration sample for translated entries, Smart Strings, fallback behavior and CJK/RTL font setup.

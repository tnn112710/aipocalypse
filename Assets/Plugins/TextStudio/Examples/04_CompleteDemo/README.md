# Text Studio Complete Demo

Whisperwood Letters is the capstone after the Learn path and Production Examples. It combines menus, prompts, exploration, dialogue, waits, input, choices, events, rewards, pause, credits, and restrained effects in one small playable vignette.

Open `Whisperwood/TextStudioWhisperwood_Canvas.unity` for the TextMeshPro Canvas backend or `TextStudioWhisperwood_UIToolkit.unity` for the UI Toolkit backend. Both run the same flow.

Use the Canvas scene to inspect the complete GameObject hierarchy and prefab instances. Use the UI Toolkit scene to inspect the equivalent production setup through its `UIDocument` plus the referenced UXML and USS. Shared story content lives in a ScriptableObject so both backends consume the same NPC, dialogue, position, and color data.

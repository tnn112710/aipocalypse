# 🎣 Fishing for Animal Controller (FAC)

Thank you for purchasing **Fishing for Animal Controller (FAC)**!  
I’ve put a lot of effort into creating this extension, and it means a lot that you’ve chosen to include it in your project. I hope you enjoy adding fishing mechanics to your game!

FAC is an **Addon for Malbers’ Animal Controller (AC)**.  
This means **you must have Animal Controller installed** before using any of the features included in this package.

If you already have Animal Controller (and love it as much as I do!), you’ll find a lot of value here. This addon is hand-crafted to make your fishing experience simple, flexible, and fun. Enjoy!

---

## 🧭 Installation Guide

1. **Install Animal Controller (AC):**  
   Make sure it’s working correctly. You can test by opening and playing one of AC’s demo scenes.  
   📘 Check Malbers’ official documentation if you need help:  
   [Animal Controller Documentation](https://malbersanimations.gitbook.io/animal-controller)

2. **Install Fishing for Animal Controller (FAC):**  
   Once AC is properly set up, download and import this addon from the Asset Store.  
   You can open and play one of the FAC demo scenes — no extra setup is required!

KROMA ATMOSPHERE TOOLKIT - DEMO SCENE INSTRUCTIONS
===========================================================================

Thank you for choosing Kroma! This document will guide you through setting 
up and exploring the included profiles. 

---------------------------------------------------------------------------
1. PRE-REQUISITES & DEPENDENCIES
---------------------------------------------------------------------------
Please ensure your project meets the following requirements:

* Project Pipeline: Universal Render Pipeline (URP)
* Unity Version: Unity 6 or newer

---------------------------------------------------------------------------
2. HOW TO TEST THE KROMA DEMO SCENE
---------------------------------------------------------------------------
1. Navigate to: Assets/Faylabs/Kroma/Scenes/Demo_Scene.
2. Switch from Scene view to Game view to see exactly what the camera sees.
3. On the top menu, open Kroma Browser (Tools > Kroma > Kroma Browser).
4. On the Kroma setup modal, click on "Initialize Kroma".
5. The Kroma Browser will open. Click "Apply" on any profile to completely 
   transform the mood of the scene instantly.
6. In the Hierarchy, you can select the "Kroma Scene Profile" game object 
   for quick adjustments.

CONGRATS! You just learned how to setup any scene with Kroma.

---------------------------------------------------------------------------
3. IMPORTANT! ALWAYS CLONE BEFORE CUSTOMIZING!
---------------------------------------------------------------------------
To safeguard your design and keep defaults intact, always use the 
"Clone Profile" button from the "Kroma Scene Profile" inspector before 
tweaking skyboxes or post-processing settings attached to profiles!

If you modify a base profile without cloning it first:
* You will alter that Kroma profile's default preset.
* The changes will affect every other scene in your project that uses 
  that same profile.
